# Gold Coast Auctions – clickable mockup

Static HTML/CSS mockup of Ron Riess's planned Wix site (gcauctionsllc.com), built from the
"Gold Coast Auctions - Website & Automation Sketch" doc (Nov 9, 2026).
Everything is sample content. Bid buttons open placeholder pages under /go/, not real marketplaces.
Open index.html. Tick "Show the Wix pieces" in the yellow banner to see which Wix element builds each block.
